# 🚀 Developer Profile Launcher

A Python-based automation project that launches developer platforms directly from the terminal and checks their website status in real time.

This project demonstrates Python automation, HTTP requests, logging, and browser integration using beginner-friendly concepts.

# 📌 Features

✅ Opens developer websites automatically  
✅ Checks website online/offline status  
✅ Displays HTTP status codes  
✅ Measures website response time  
✅ Logs all activities into a log file  
✅ Menu-driven command line interface  
✅ Beginner-friendly Python project  


# 🛠️ Technologies Used

- Python 3
- Webbrowser Module
- Requests Module
- Logging Module
- Time Module

# ▶️ How to Run the Project


```bash

```


# 💻 Project Workflow

1. User selects a website from the menu
2. Python opens the website in the browser
3. Program sends an HTTP request
4. Displays:
   - Website status
   - HTTP response code
   - Response time
5. Logs all activities into a log file
